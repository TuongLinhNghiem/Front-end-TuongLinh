# TryItOn! — Fashion Outfit Design Platform

A proof-of-concept web application for designing and saving digital outfits on a layered 2D avatar. Built as a university thesis project and the foundation for a future startup. **This is not an e-commerce site** — it is an outfit design and recommendation platform.

## Features

- **User accounts** — register, log in, log out (bcrypt password hashing, express-session authentication, SQLite storage).
- **Dashboard** — personalised greeting and navigation cards to every tool.
- **Avatar Designer** — a layered 2D PNG avatar (head / body / legs / hat). Pick a colour (red, blue, yellow) for each garment layer and see the preview update instantly. No AI, no 3D — pure 2D image compositing.
- **Outfit Designer** — combine a shirt, pants and hat into a named outfit. Save it to your wardrobe (stored in SQLite with the outfit name, date and colour choices). Edit existing outfits too.
- **Wardrobe** — browse every saved outfit as a card with a live avatar preview, colour swatches, and Edit / Duplicate / Delete actions.
- **Shop** — three demo shops, each themed around a single colour (Shop A = red, Shop B = blue, Shop C = yellow). Browse shirts, pants and hats. No checkout — this is a browsing experience.
- **Recommendations** — multi-select the colours you want for shirt, pants and hat. The app ranks every shop by how many of your picks it stocks and highlights the best match. No AI — a simple, transparent colour/category matching filter.
- **Profile** — view your username, email, avatar, member-since date and body measurements (placeholder). Edit your profile through a modal.

## Tech Stack

| Layer        | Technology                                      |
| ------------ | ----------------------------------------------- |
| Frontend     | HTML5, CSS3 (custom properties), Vanilla JS    |
| Backend      | Node.js, Express.js                             |
| Database     | SQLite (via the `sqlite3` package)              |
| Auth         | `bcrypt` (password hashing), `express-session`  |
| Avatar assets| 2D PNG layers generated from SVG (Python cairosvg script included) |

No frontend framework. All interactivity is progressive enhancement on top of working HTML forms.
